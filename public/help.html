五分钟上手

  1. 装 Node.js 18+，双击 启动.bat，浏览器会打开 http://127.0.0.1:8713。
  2. 右下角「设置」→ 填 DeepSeek API Key（没有 Key 可先开「演示模式」）。
  3. 左上角「+」新建科目，写一句你的分类标准（可留空）。
  4. 「上传课件」，把上课拍的 PPT 照片拖进去，等识别完成。
  5. 看「知识点」「分类」，用「导出」带走 Markdown，用「完整备份」留底。

下面各章按实际操作顺序展开；遇到问题直接跳到最后一章「常见问题」。

一、这是做什么的

把一学期的课件截图（PPT 拍照、PDF 截屏）丢进来，程序会调用大模型逐页识别：转录文字、抽出一页里真正值得记的 1~4 条知识点、再补充一些背景与考点（标为「拓展」）。之后可以按你自己的标准整理成多级目录，导出成可离线阅读的笔记，或者用手机随时翻。

三件事需要你知道：

  • 图片和笔记全部存在你自己的电脑（或手机）里，只有截图和文字会发送给模型服务。
  • AI 补充的「拓展」条目都带标注，和被老师讲到、有原文出处的「知识点」分开显示。
  • 每条知识点都带原文片段，点一下能跳回对应课件原页核对。

二、安装与启动

2.1 电脑版（Windows）

  1. 安装 Node.js 18 或更高版本（nodejs.org，装默认选项即可，只需装一次）。
  2. 解压项目文件夹，双击 启动.bat。会弹出一个黑色命令行窗口——它要一直开着。
  3. 浏览器自动打开 http://127.0.0.1:8713。若 8713 被占用，程序会自动换到 8714、8715……实际地址看窗口里打印的那行。
  4. 不想看到窗口：双击 后台启动.vbs（静默运行）。想让它开机就起来：双击 安装开机自启.bat。
  5. 用完停止：关闭命令行窗口，或双击 停止.bat。

提示：日常使用断网也能打开界面，只是识别和改写需要联网。

2.2 手机版（APK）

  1. 把 MakeYourNotes-v2.9.10.apk 传到手机（微信文件传输助手、数据线都行）后点开安装。
  2. 若提示「开发者身份未验证 / 未知来源」：在提示页选「仍然安装」，或在 Play 商店 → Play Protect 里关闭「扫描应用」再装。
  3. 首次启动会解压资源，看到启动动画后约 2~5 秒进入界面。
  4. 手机版不连电脑、不需要 WiFi（除调用模型外），数据存在手机应用私有目录。

手机版只支持 arm64 机型（2017 年后的手机基本都满足）；卸载才会删数据，用同一签名覆盖安装会保留数据。

三、第一次使用：填 Key

右下角「设置」里有这几项（不同版本措辞略有差异，位置一致）：

设置项怎么填
供应商 / 接口地址默认 DeepSeek（https://api.deepseek.com）。用中转或本地模型时改成对方地址
API Key在 platform.deepseek.com → API keys 创建，粘贴进来，点「测试」确认连通
识别模型（要能读图）默认已填好；换模型时这里必须选能看图的模型，否则识别会报错
文字模型（整理/改稿/起草）纯文本模型即可，默认 deepseek-chat
并发数一次同时识别几页。默认 1~2 即可；免费模型建议设 1，避免触发限流
推理等级关闭 / 低 / 高 / 最大。越高越慢越贵，一般「低」够用

没有 API Key 也能先体验：设置里打开「演示模式」，识别会返回示例数据，不消耗额度。

四、建科目与分类标准

一个科目 = 一门课。建的时候可以填「你希望怎么分类」，例如：「按 电路 / 模电 / 数电 三大块分；公式题单独归到「计算」；不要出现「其他」。」这句话会在「自动整理」时交给模型，所以写得越具体，整理结果越合你意。留空也能用，之后随时在科目里改。

五、上传课件并识别

5.1 三种上传方式

  • 电脑拖拽：把图片文件直接拖进窗口，会整屏高亮提示「松开上传」。
  • 电脑粘贴：截图后按 Ctrl+V，直接粘进当前科目。
  • 手机 / 电脑选图：点「上传课件」从相册（或文件管理器）多选，手机上也可以直接拍照。

图片会被压缩到长边 1800px 再上传，原图只留在本机，所以拍歪、反光也能试，但清晰度会影响识别准确率。

5.2 识别过程

上传后程序逐页调用模型：先转录整页文字，再抽 1~4 条知识点（每条带原文片段），最后补充拓展内容。右下角会显示「后台识别中 3 / 12」的进度；关掉浏览器也不影响，回到页面结果已经在了。

识别失败的页面会在卡片上直接写原因（例如 Key 不匹配、限流、模型不支持图片）。开了「严格校对」的话，模型会拿原图再比对一次草稿，只改字符级差异，更准但更慢更贵。

六、看知识点

每张卡片显示：标题、正文前几行、公式（有的话）、标签、重要度圆点、来自第几页。卡片太长会自动折叠，折叠行数可以在设置里改（-1 不折叠、0 只看标题）。

6.1 详情页

点卡片进入详情。这里能看到完整正文、公式（可放大）、原文片段、标签、重要度，以及「跳转原文」直接看那页课件。

6.2 让 AI 改这一条

在详情页写一句要求，例如「把解释压到两行」「补一个数值例子」「把推导补上」，AI 会结合本页原文重写这一条。改完保留旧版本，弹窗里可以「撤销」。如果不希望公式被改动，设置或编辑器里的「保留原公式」打开即可。

七、自动整理目录

点「自动整理」，程序把当前科目的全部知识点（连同你的分类标准）交给模型，由它给出归类方案，可建 2~3 层目录。整理结果不满意就再点一次；也可以手动把条目拖到别的分类，或改名、删分类。

八、分类视图与思维导图

「分类」标签页默认按目录列出；点右上角「导图」切换成树状导图，支持双指缩放、拖动、点节点跳到该知识点。导图可以导出成 PNG 或 SVG 放进 PPT。

九、手写笔记与符号键盘

除了从课件里提取，也可以「+ 新建笔记」自己写：标题、正文、公式三块，正文支持 LaTeX 实时预览。输入框聚焦时用符号键盘点选 μ、∂、∑ 这类符号，会插到光标处。手动笔记可以挂在某一页课件下，也可以只属于科目。

十、画板与电路图

详情页「配图」栏里点「✎ 画配图」进入画板：画笔、常用图形、文字、40 个电子元件、连线、自定义芯片都在这里。画完插进当前笔记，随笔记一起保存与导出。

  • 连线：点起点、再点终点，自动走直角并绕开元件；端点靠近引脚会自动吸附。
  • 芯片：先设名称和每边引脚数，再拖出矩形放置，引脚可改编号与名称。
  • 组合：框选多个元件后可整体移动、旋转 90°、成组缩放。
  • 撤销/重做：顶栏图标按钮，误操作随时退回。

十一、导出

顶部「导出」菜单里有五种产物，按用途选：

导出项适合什么场景说明
Markdown粘到别的笔记软件、Notion、Obsidian公式写成 $$…$$；末尾附「来源与核验」段落
学习笔记 HTML（图文文档）发给别人看、打印成 PDF公式与配图内联，双击即开，完全离线
公式合集考前只背公式按分类汇总本页所有公式，带 KaTeX 渲染
思维导图（SVG / PNG）放进 PPT 或打印矢量，放大不糊
JSON（仅文字）自己写脚本处理不含图片

十二、备份与恢复

  1. 「导出」→「完整备份（含设置与用量）」，得到一个 zip（里面是数据、图片与设置）。
  2. 把 zip 存到网盘或 U 盘；建议每月一次，交作业/换电脑前务必备一次。
  3. 换机器后：点「从备份恢复」，选择 zip；同名科目会合并，重复条目自动跳过。

旧版备份（不含图片）也能恢复，但图片可能缺失，因为老格式只存了文件路径。

十三、在手机上用

13.1 两种方式

  • 装 APK：完全在手机上运行，不需要电脑（见第二章）。
  • 扫码访问：电脑开着时，手机扫「手机访问」的二维码，同一套数据、同一个 WiFi 即可。

扫码打不开时：① 确认手机和电脑在同一 WiFi；② 第一次运行时 Windows 防火墙弹窗要点「允许访问」；③ 校园网/公司网常会隔离设备，换手机热点试试。

十五、费用与用量

识别一页大约 1 分钱，一门课几十页大约几毛到一两块。「用量」面板能看到调用次数、token（含缓存命中）与折算金额，按天出折线图。

  • 省钱做法：识别时并发 1、不需要时关掉严格校对；整理和改稿用便宜的文字模型。
  • 遇到 429/5xx：程序会自动退避重试并转单线程，等一会儿再继续即可。

十七、数据与隐私

  • 笔记、课件图片、设置、用量都存在本机（电脑是项目目录下的 data/，手机是应用私有目录）。
  • 只有课件截图和文字会发送给模型服务商；不经过本项目作者的服务器（本项目没有服务器）。
  • API Key 保存在本机，界面上不回显明文。
  • 卸载手机 App 会删除数据；覆盖安装同签名 APK 会保留数据。

本手册对应版本 v2.9.10；界面文字在后续版本可能有微调，以实际界面为准。最新版本与更新记录见 CHANGELOG.md。
